# Встроенный процесс «цель» (docs/07-extension-mode.md §5, D35): задача без своего процесса.
# Текст цели — описание задачи: `teo new KEY --goal "…"`. Свой ~/.pi/teo/goal.md заменяет этот файл.
schema: teo/v1

workflow:
  initialStage: pursuit
  stages:
    pursuit:
      title: Достижение цели
      agent: performer
      description: Цель сформулирована в описании задачи.
      transitions:
        - to: reached
          when: >
            Цель из описания задачи достигнута полностью, и это подтверждено
            проверяемыми фактами: файлами, коммитами, выводом команд или явным
            ответом пользователя. Заявления агента без фактов не считаются.
          guards:
            evidence: required

    reached:
      title: Цель достигнута
      terminal: true

agents:
  performer:
    title: Исполнитель цели
    model: default
    instructions: |
      Твоя задача — достичь цели, сформулированной в описании задачи.

      1. Если цель неоднозначна и от уточнения зависит результат, спроси
         пользователя через ask_user. Не задавай вопросов, ответ на которые
         можно найти в проекте.
      2. Делай только то, что нужно для цели. Не расширяй её сам.
      3. Проверь результат так, как его проверил бы пользователь.
      4. Отчитайся через report_result: в evidence укажи проверяемые факты
         (artifact:, git:, run:, human:). Если цель недостижима — report_blocker
         с причиной.

supervisor:
  model: default
  instructions: |
    Цель задачи — в её описании, другой спецификации нет.
    Переход в «Цель достигнута» — только когда факты подтверждают цель целиком.
    Не придумывай требований, которых нет в описании. Если чего-то не хватает,
    продолжи агента с конкретным замечанием; если цель недостижима или
    противоречива — спроси пользователя.

runtime:
  policyChangeMode: latest
  maxCyclesPerStage: 8
---

# Правила процесса

Задача поставлена одной целью без процесса.

- Отчёт агента — заявление, а не доказательство.
- Результат проверяется по фактам: файлам, коммитам, выводу команд, ответам пользователя.
